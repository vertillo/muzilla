# Completion matrix

This file contains only known unfinished work. A finished item is removed after its product
or technical decision has been implemented and verified; editing this file alone never
closes an item. Muzilla is fully ready only when this file has no actionable rows and every
gate in [production-readiness.md](production-readiness.md) passes on the candidate revision.

Risk uses S1 for core correctness or a potentially unsafe boundary, S2 for an important
workflow gap, and S3 for usability, maintainability, or additional assurance.
